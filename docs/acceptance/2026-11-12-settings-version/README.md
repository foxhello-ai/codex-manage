# 设置页当前版本字段

状态：已实现，尚未合并 main、尚未发布。正式 v1.0.10 包不包含这个新字段。

位置：设置和诊断 → Web 服务 → 当前版本。

正式安装读取正在运行的包内 `build-info.txt`，显示如 `v1.0.10`；源码启动显示“源码版（提交号）”，有代码变更时提示“本地修改”。缺少可信记录时显示“未知版本”，不使用根 package.json 的 1.0.0 冒充 Runtime 版本。

版本信息按进程启动时固定，升级替换文件后，旧进程不会把新包版本当成自己的版本。

验证：5 项相关测试、类型检查和生产构建通过。编译后的配置路由在独立目录读取正式 v1.0.10 包的元数据，即使工作目录不在安装目录，也返回正确版本；替换元数据后同一进程仍返回原版本。桌面与 375px 手机预览无横向溢出，“重新检查”后字段正常。

截图为隔离 UI 预览，健康状态及路径为测试数据；版本值使用现有 v1.0.10 包元数据，不代表旧发布包已新增字段。未修改现有 main 服务。
