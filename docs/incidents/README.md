# 故障记录索引

本目录用于集中索引已发生、已定位或仍在跟踪的生产及交付故障。详细分析可以保留在 `docs/implementation-notes`，但必须在此登记故障编号、状态、影响与文档入口。

## 状态定义

- `分析中`：现象已确认，根因尚未完成证据闭环。
- `待修复`：根因已确认，修复尚未合入。
- `待验证`：修复已完成，回归或真实环境验证未结束。
- `待发布`：代码与验证完成，尚未进入正式发布包。
- `已关闭`：修复已发布并完成目标环境验收。

## 新增故障记录要求

每条故障至少记录：

1. 唯一故障编号、日期、状态、严重程度和影响范围。
2. 用户可见现象与可搜索的关键错误文本。
3. 已确认根因，并区分下游症状和推断项。
4. 具体代码位置、修复方案和关联提交。
5. 自动化验证、真实环境验证和剩余发布事项。
6. 回滚方式、关闭条件和后续责任项。
