# H5 会话列表抽屉和备注标题需求记录

## 基本信息

- 日期：2026-07-14
- 类型：需求补充
- 影响范围：会话列表、H5 移动端交互、会话元数据、后续 M3/M4 实现

## 需求内容

### H5 会话列表交互

H5 移动端展示时，会话列表不应一直占据主界面空间。

要求：

- 会话列表默认收起。
- 使用侧边栏或抽屉承载会话列表。
- 用户点击会话列表按钮后展示列表。
- 抽屉内必须保留搜索能力。
- 抽屉应有明确关闭方式。
- 用户选择某个会话后，抽屉关闭并进入对应会话内容。

### 会话备注标题

允许用户为对话设置备注标题。

要求：

- 支持设置、修改、清空备注标题。
- 会话列表主标题优先展示备注标题。
- 没有备注标题时，回退展示 Codex thread name、首条消息摘要或 session id。
- 搜索应覆盖备注标题。
- 备注标题是 Codex Manage 的展示元数据，不应修改 `~/.codex/sessions` 原始会话文件。

## 设计影响

- 需要增加 Web 管理台自身的会话元数据存储。
- MVP 可使用本地 JSON 元数据文件，后续可替换为数据库。
- 需要新增或扩展 API，例如 `PATCH /api/sessions/:id/metadata`。
- H5 UI 需要从当前直接展示列表调整为列表按钮 + 抽屉式列表。

## 验收补充

- H5 首屏不直接展开完整会话列表。
- 点击会话列表按钮后展示侧边栏/抽屉。
- 抽屉内可以搜索会话。
- 备注标题可设置、修改、清空。
- 设置备注标题后，会话列表主标题立即更新。
- 清空备注标题后，主标题恢复默认标题或摘要。
