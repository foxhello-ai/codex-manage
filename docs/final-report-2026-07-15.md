- 配置记录密码来自默认值还是 `CODEX_WEB_PASSWORD`，但不返回密码内容。

## 4. M12 发现并修复的问题

1. H5 会话抽屉在详情页重构后丢失。
   - 恢复移动端默认隐藏列表、图标打开、抽屉搜索、遮罩关闭和 Escape 关闭。
2. Dashboard 未同步登录后异步返回的配置。
   - 修复列表长期显示“读取中”和“未连接”。
3. 桌面浮动运行状态覆盖详情内容。
   - 宽屏为浮层预留右侧空间；窄桌面不显示冗余浮层。
4. H5 浮动状态覆盖标题和刷新按钮。
   - 改为详情工具栏下方的紧凑可展开状态条，显示状态、连接、权限、事件和待审批数量。
5. H5 底部输入框覆盖历史回复。
   - 将消息改为独立滚动区域，输入框占据固定布局行，不再覆盖正文。
6. app-server 的 `idle` 状态被错误映射为 `history`。
   - 改为 `waiting_input`，真实双会话恢复后状态正确。
7. `willRetry: true` 的重连错误被错误标记为失败。
   - 重试期间保持 `running`，仅最终错误标记 `failed`。

- `/api/health` 返回 app-server `ready`。

### 外部环境未通过项

新模型回复连续多次收到：

```text
502 Bad Gateway
https://proxy.newbeechat.com/v1/responses
```

默认模型和显式 `gpt-5.2` 均出现相同代理错误，说明失败位于当前外部模型代理，而不是 Web 恢复、输入、WebSocket 或 app-server 本地链路。系统已正确展示重连过程、最终错误和恢复后的等待输入状态。代理恢复后应重新执行一次真实模型回复和真实审批生成，作为环境复验。
