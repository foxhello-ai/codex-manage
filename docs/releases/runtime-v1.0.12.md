# Codex Manage Runtime v1.0.12

修复桌面会话运行时，Manage Web 历史加载空白、运行进度不可见及错误提示一闪而过的问题。

## 变更

- 元信息与历史独立加载，历史失败时保留错误和重试入口，刷新失败保留已有消息。
- 复用原桌面已有的只读订阅，展示最近历史并自动同步新输出；更早历史沿用原始分页游标。
- 运行中的过程消息保持展开，同一轮较早的最终答复不再隐藏后续进度。
- 历史首屏失败时仍可通过桌面游标读取更早消息；Manage 自己持有的会话不等待桌面订阅。
- 增加历史失败请求的耗时与脱敏原因日志，便于定位远端 503。

官方桌面继续照常点原图标启动，不需要修改启动参数或后台服务。

## 验证与发布

197 项单元/集成、10 项专项浏览器测试、10 项审批与历史回归、类型检查及前后端构建通过。本机真实桌面会话验证了最近历史、新进度自动出现和更早 20 轮读取；[验收报告](../acceptance/2026-11-13-history-503/report.html) 含截图。

发布流水线还将验证安装、升级、回滚、服务启停、配置保留及实际运行版本，正式发布后补充发布包和三平台安装证据。

远端原会话的实际 503 尚未捕获。本版修复已确认的代码缺陷，远端效果需要升级后在原会话复测。

## 升级

macOS 使用当前桌面用户执行：

```bash
curl -fsSL https://github.com/foxhello-ai/codex-manage/releases/download/v1.0.12/install-runtime.sh \
  | bash -s -- --version 1.0.12
```

Linux 使用实际会话所属用户执行：

```bash
curl -fsSL https://github.com/foxhello-ai/codex-manage/releases/download/v1.0.12/install-runtime.sh \
  | sudo bash -s -- --user <实际运行用户> --version 1.0.12
```

安装器保留已有配置和数据并重启 Manage 服务。升级后刷新 Web，设置和诊断的“当前版本”应为 v1.0.12。v1.0.11 可用于回滚。
